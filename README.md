# <img src="assets/logo/logo-algebra-mart.png" alt="Algebra-Mart Logo" width="40" height="40" style="vertical-align: middle; border-radius: 8px;"> Algebra-Mart

**Algebra-Mart** adalah media pembelajaran digital inovatif bertema toko kelontong modern yang dirancang khusus untuk mentransformasi materi aljabar siswa SMP/MTs Kelas VII fase D Kurikulum Merdeka. Melalui simulasi peran kasir interaktif dengan muatan lokal Jambi dan integrasi literasi keuangan nyata, siswa memetakan barang belanjaan menjadi bentuk aljabar, mengelola transaksi pembayaran, serta menyelesaikan kuis evaluasi bertingkat untuk membangun pemahaman konseptual yang mendalam.

##  Fitur Unggulan

- **20 Level Berjenjang & 5 Fase Aljabar**: Dari konsep variabel tunggal hingga sifat distributif kontekstual.
- **Simulasi Kasir Interaktif**: Keypad kalkulator aljabar, perhitungan struk kasir, uang pembayaran, dan kembalian.
- **Kearifan Lokal Jambi**: Representasi belanja dodol nanas, kue padamaran, beras payo, kopi AAA, dan tempoyak.
- **Mode Kelas & Ruang Fasilitator**: Dashboard guru untuk pemantauan capaian belajar siswa secara real-time.
- **20 Lencana Prestasi & 6 Gelar Kasir**: Sistem gamifikasi bertingkat untuk menjaga motivasi belajar.
- **Buku Instruksi Lengkap**: Panduan terintegrasi yang dapat dibaca online secara interaktif melalui Heyzine flipbook maupun diunduh langsung dalam format PDF.

```

├── .gitignore       # Konfigurasi pengabaian berkas repositori
└── README.md        # Dokumentasi resmi proyek
```

##  Menjalankan Secara Lokal

Cukup jalankan satu perintah berikut di terminal:

```bash
python -m http.server 8000
```

Lalu buka peramban web pada alamat `http://localhost:8000`.
